## 백업과 복원

개인 옷장에서는 기존 스키마의 JSON으로 의류, 원본 사진, 미리보기, 의류 ID를 참조하는 코디를 내보낸다. 이전 버전 백업도 가져올 수 있다. 등록 원본은 이미지 처리기로 다시 검증하고 SHA-256과 대조한다. 구매 내역만 있는 의류는 사진 없이 복원한다. 새 의류·코디는 한 트랜잭션에서 추가한다. 기존 기록은 유지하고 사진 해시가 같으면 그 기기의 기존 ID로 코디를 연결한다. 파일 가져오기는 192MB까지 지원한다.

현재 모드의 활동(모델 설정·참고 사진·착용 기록·취향 등)은 별도의 읽기용 JSON으로 내보낸다. 이 파일의 자동 가져오기는 제공하지 않는다. 삭제 범위를 표시한 뒤 사용자가 확인 문구를 입력한 경우에만 해당 모드 자료를 지운다. 사용자의 의류·코디 및 기기 활동을 서버로 백업하거나 전송하지 않는다.

## 실행·검증 경로

Vercel은 루트 `api/*.js`를 서버 함수로 실행한다. `vite.config.js`는 같은 핸들러를 개발·미리보기 서버에 등록한다. iOS 오프라인 번들의 로컬 정적 서버에서는 외부 조회를 사용할 수 없다. 공급자 모의 응답으로 날씨 매핑·동시 요청 병합·캐시·오류, 상품 가격 파싱·연동 미설정·검색어 검증을 검사했다. 운영 예보 및 승인된 쇼핑 검색 확인은 실제 공급자 응답과 별개로 추적한다.
